# 🛒 বাজার দর | BazarDor

### 🇧🇩 বাংলাদেশের নিত্যপ্রয়োজনীয় পণ্যের দৈনিক বাজারদর

**BazarDor** is a modern, user-friendly web application that helps people explore daily prices of essential products in Bangladesh. It makes it easier to check current market prices, compare price changes, and stay informed about everyday shopping costs.

> 💚 **Know the price. Shop smarter. Save more.**

---

## ✨ Key Features

* 📊 **Daily Market Prices** — Browse the latest available prices of essential everyday products.
* 📈 **Price Change Tracking** — Check whether product prices have increased, decreased, or remained unchanged compared with previous periods.
* 🗂️ **Category-Based Browsing** — Explore products through organized categories for a smoother shopping experience.
* 🔐 **Secure Authentication** — Create an account or sign in using email and password, Google, or GitHub.
* 👤 **Personalized User Profile** — View your account information and display a profile picture using an image URL.

---

## 🛠️ Technologies Used

| Technology      | Purpose                                       |
| --------------- | --------------------------------------------- |
| Next.js         | React framework and application routing       |
| React           | Building reusable user interface components   |
| TypeScript      | Type safety and maintainable code             |
| Tailwind CSS    | Responsive styling and modern UI design       |
| DaisyUI         | Ready-to-use UI components                    |
| Better Auth     | User authentication and session management    |
| MongoDB         | Database for authentication-related user data |
| React Hot Toast | Success and error notifications               |
| React Icons     | Icons for buttons and interface elements      |
| BazarDor API    | Fetching product and market price information |

---

## 🎯 Project Goal

BazarDor aims to make daily market price information more accessible to people in Bangladesh. By presenting product prices and price changes in a simple interface, it helps users make more informed shopping decisions.
